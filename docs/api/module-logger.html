Module: logger

Logger applicatif centralisé (Winston).

  • Sortie console au format JSON (collectée par Docker / Dozzle).
  • Si LOG_DIR est défini : fichiers error.log, combined.log et audit.log avec rotation par taille (5 Mo x 5 fichiers).
  • logger.audit(event, meta) trace les événements sensibles (connexion, inscription, actions admin) dans un journal d'audit dédié.
