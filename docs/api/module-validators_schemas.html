Module: validators/schemas

Schémas de validation Joi des entrées utilisateur. Toute requête est validée AVANT d'atteindre les contrôleurs : types stricts, longueurs bornées, listes de valeurs autorisées, champs inconnus rejetés (protection contre l'injection d'opérateurs MongoDB et l'affectation de masse, ex : { "role": "admin" }).
