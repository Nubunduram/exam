Methods

(static) authenticateToken()

Vérifie le JWT de la requête et expose son contenu dans req.user ({ userId, role }). Le token est lu en priorité dans le cookie httpOnly (inaccessible au JavaScript du navigateur, donc protégé contre le vol par XSS), sinon dans l'en-tête Authorization: Bearer <token> (clients API, tests).

Réponses : 401 si aucun token, 401 si token invalide ou expiré.

(static) isAdmin()

Autorise uniquement les administrateurs. Doit être placé après authenticateToken. Réponse : 403 si l'utilisateur n'a pas le rôle "admin" (tentative journalisée en audit).
