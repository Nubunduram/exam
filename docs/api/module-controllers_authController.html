(static) login() → {200}

Connecte un utilisateur. Corps validé par Joi : { username, password }. Message d'erreur générique (pas d'énumération des comptes) et comparaison bcrypt systématique (temps de réponse constant). Le JWT est déposé dans un cookie httpOnly.

(inner) cookieOptions() → {express.CookieOptions}

Options du cookie de session :

  • httpOnly : illisible par le JavaScript du navigateur (protection XSS) ;
  • secure : envoyé uniquement en HTTPS (désactivé seulement en local via COOKIE_SECURE=false) ;
  • sameSite strict : non envoyé par un site tiers (protection CSRF).
