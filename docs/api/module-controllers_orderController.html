(static) createOrder() → {201}

Crée une commande pour l'utilisateur connecté.

Sécurité : le prix et le total envoyés par le client sont ignorés ; ils sont recalculés à partir des prix en base. Le stock est réservé de façon atomique (décrément conditionnel stock >= quantité) et restitué si une étape échoue.

Corps validé par Joi : { items: [{ productId, quantity }], shippingAddress, paymentMethod, shippingMethod }
