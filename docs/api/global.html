(async) connectDB() → {Promise.<void>}

Établit la connexion à MongoDB à partir de la variable MONGO_URI. L'URI n'est jamais journalisée (elle contient des identifiants). Arrête le processus si la connexion initiale échoue (Docker le redémarre).

validate(schema, sourceopt) → {express.RequestHandler}

Fabrique un middleware Express qui valide une partie de la requête avec un schéma Joi. En cas d'erreur : réponse 400 avec un message lisible par l'utilisateur. En cas de succès : la partie validée est remplacée par sa version nettoyée (espaces supprimés, champs ignorés retirés, types convertis).

Name Type Attributes Default Description

Partie de la requête à valider.
